# 問い合わせ用エラーコード

画面に表示された `SQ-...` を問い合わせ時に控える。コードは失敗した処理を示し、通信障害や権限設定などの根本原因を単独で確定するものではない。開発ログにも同じコードを記録するが、リリース版では例外の詳細を画面やログに出さない。

| コード | 処理 | 最初に確認する箇所 |
| --- | --- | --- |
| SQ-START-01 | 起動の必須処理 | 認証、イベント選択、獲得履歴同期 |
| SQ-MAP-01 | スポット一覧 | イベント ID、スポット API |
| SQ-GPS-01 | 位置情報サービス OFF | 端末の位置情報設定 |
| SQ-GPS-02 | 位置情報の許可なし | アプリの権限設定 |
| SQ-GPS-03 | 位置情報の恒久拒否 | 端末のアプリ権限設定 |
| SQ-GPS-04 | 初回位置取得 | GPS、端末設定、位置サービス |
| SQ-GPS-05 | 位置ストリーム | GPS、位置サービス |
| SQ-EVENT-01 | クエスト切り替え | イベント選択と参加更新 |
| SQ-RANK-01 | ランキング | ランキング RPC |
| SQ-NEWS-01 | お知らせ | 公開お知らせの取得 |
| SQ-SYNC-01 | 同期状態の確認 | 保留データの読み込み |
| SQ-SYNC-02 | 同期の再試行 | 保留データの送信 |
| SQ-LOG-01 | 冒険ログ | 履歴一覧の取得 |
| SQ-PROFILE-01 | プロフィール読み込み | 認証とプロフィール取得 |
| SQ-PROFILE-02 | プロフィール保存 | 認証、入力、プロフィール更新 |
| SQ-DETAIL-01 | 札の詳細 | スポット一覧と獲得履歴 |
| SQ-EVENT-02 | クエスト一覧 | 参加状態の読み込み |
| SQ-SYNC-03 | 獲得履歴のリセット | 履歴削除と同期 |
| SQ-AUTH-01 | アカウント認証 | メール、確認コード、ログインと認証状態 |
| SQ-WEATHER-01 | 天気の取得 | 天気 API、通信状態、再取得間隔 |

コードは `lib/services/app_error_report.dart` に定義する。新しいコードを追加したらこの表も更新し、既存コードを別の用途に再利用しない。
