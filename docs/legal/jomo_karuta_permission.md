# 上毛かるた利用許諾・運用記録

## 許諾内容

- 対象アプリ：スマートフォン向け位置情報周遊アプリ「聖地クエスト」
- 許諾元：群馬県（文化振興課）
- 許諾申請日：2026年9月24日
- 許諾通知日：2026年10月1日
- 許諾番号：**08-01054**（通知書の表記：許諾第08-01054号）
- 許諾対象：全絵札・全読み札
- 利用期間：2026年10月1日～2027年3月31日

## 守るべき条件

1. 許諾された用途・対象以外には使用しない。
2. 絵札・読み札を改変しない。
3. 絵札は一部を欠けさせず、全体が見えるように表示する。
4. 読み札は文字が読めるように表示する。
5. 縮小・拡大時は縦横比を変更しない。
6. 表記は「上毛かるた」とする。
7. 許諾番号を、原則として許諾対象物件に明示する。
8. 利用後30日以内に利用報告書を提出し、完成品または利用状況が分かる写真を添付する。
9. 利用期間終了後も継続する場合は、期間満了前に更新申請する。

## リリース前後の確認事項

- [ ] 絵札・読み札が切れず、読み札の文字が読め、縦横比が維持されることを実機確認する。
- [ ] 実際の利用開始日と利用報告期限を確定する。
- [ ] 群馬県公式ページから利用報告書の様式を取得し、利用状況が分かる写真を添えて提出する。
- [ ] 利用開始が許諾期間前だった場合は、群馬県文化振興課に経緯を伝え、扱いを確認する。
- [ ] 2027年3月31日までに継続利用の要否を判断し、必要なら満了前に更新申請する。
