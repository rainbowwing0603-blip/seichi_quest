聖地クエスト プライバシーポリシー

聖地クエスト運営（以下「運営者」といいます）は、 スマートフォンアプリ「聖地クエスト」（以下「本アプリ」といいます）における 利用者情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

本アプリは、位置情報を利用して実際の場所への訪問を判定し、 スタンプ・コンテンツの獲得などの体験を提供する位置情報型サービスです。

1. 取得・利用する情報

位置情報

本アプリは、現在地の表示、目的地までの距離表示、訪問判定、 スタンプ・コンテンツの獲得判定などのため、 端末の位置情報を利用します。

訪問または獲得の記録には、緯度・経度、位置情報の精度、 訪問日時などが保存される場合があります。

アカウント情報

本アプリでは、サービス提供のためユーザーを識別するIDを利用します。 また、利用者がアカウント登録または設定を行った場合、 メールアドレス、表示名、年代、プロフィール画像に関する情報などを 取り扱う場合があります。

パスワードによる認証を利用する場合、認証処理にはSupabase Authを利用します。

利用履歴

本アプリでは、スタンプ・コンテンツの獲得履歴、訪問履歴、 イベントへの参加状態、現在選択しているイベント、 お気に入りなど、本アプリの利用に必要な情報を保存する場合があります。

広告に関連する情報

本アプリでは広告配信のためGoogle Mobile Ads（AdMob）を利用します。 広告サービス提供者により、端末情報、広告識別子、 IPアドレス、広告の表示・操作に関する情報などが 取得または利用される場合があります。

2. 情報の利用目的

取得した情報は、主に以下の目的で利用します。

  • 現在地の表示および位置情報を利用したサービスの提供
  • 訪問、スタンプおよびコンテンツ獲得の判定
  • 獲得履歴・訪問履歴の保存および同期
  • イベント参加、お気に入り等の機能提供
  • ランキング等、本アプリ内機能の提供
  • ユーザーアカウントおよびプロフィールの管理
  • 広告の表示および広告サービスの提供
  • 不正利用の防止、サービスの安全性および品質の維持
  • お問い合わせへの対応

3. 外部サービス

本アプリでは、サービス提供のため外部サービスを利用する場合があります。 各サービスにおける情報の取扱いについては、 各サービス提供者のプライバシーポリシー等をご確認ください。

  • Supabase：認証、データ保存および同期等
  • Google Maps Platform：地図表示等
  • Google Mobile Ads（AdMob）：広告配信
  • Open-Meteo：天気情報の取得

4. 位置情報について

位置情報は、本アプリの主要機能である訪問判定、 スタンプ・コンテンツ獲得判定、地図表示等のために利用します。

位置情報の利用許可は端末の設定から変更できます。 ただし、位置情報を許可しない場合、 本アプリの一部または主要な機能を利用できない場合があります。

5. 広告について

本アプリではGoogle Mobile Ads（AdMob）を利用して広告を表示する場合があります。 広告配信に伴う情報の取扱いは、 Googleのプライバシーポリシーおよび関連する規約等に従います。

6. 情報の第三者提供

運営者は、法令に基づく場合を除き、 利用者の個人情報を本人の同意なく第三者へ販売することはありません。

ただし、本アプリの機能提供に必要な範囲で、 本ポリシーに記載した外部サービスを利用し、 必要な情報が各サービス提供者によって処理される場合があります。

7. 情報の安全管理

運営者は、本アプリで取り扱う情報について、 不正アクセス、漏えい、滅失または改ざん等を防止するため、 合理的な安全管理措置を講じるよう努めます。

8. アカウントおよびデータの削除

アカウントを削除すると、アカウントに紐づくデータも削除されます。

アカウントを利用している場合、本アプリ内の 「アカウントを削除」機能から削除手続きを行うことができます。

アカウント削除に伴い、プロフィール、獲得履歴、訪問履歴、 イベントの参加状態、イベント選択情報、お気に入りなど、 当該アカウントに紐づくデータが削除されます。

削除したアカウントおよび削除されたデータは、 原則として復元できません。
