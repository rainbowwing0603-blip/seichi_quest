# プロダクト概要

## 目的
聖地クエストは、実在地点への訪問をGPSで確認し、イベントに紐づくコンテンツを収集するFlutterアプリである。現在の代表イベントは上毛かるた×群馬を題材とするが、設計上は地域・店舗・商品・作品/IPコラボ等へ拡張できるイベント型プラットフォームを目指す。

## 実装済み
- Androidアプリ。applicationId / namespace は `jp.seichiquest.app`。
- Google Mapsによる地図、現在地、目的地表示。
- GPS訪問とサーバー側獲得処理。
- 端末キャッシュとSupabase同期。
- イベント切替、スタンプ帳、チャレンジ、ランキング、マイページ系画面。
- 汎用コンテンツブロック。
- AdMob、ローカル通知。
- Supabase Auth / Database / Storage / Edge Function。
- Noto Sans JPをアプリ全体のフォントとして使用。

## 現在のデータ
本番Supabase確認時点で、イベント2、旧`seichi`44、`places`41、`contents`44、`event_contents`44、`content_blocks`221。旧モデルと汎用モデルが併存している。

## 将来構想
全国の移動・観光クエスト、自治体・店舗・商品・企業・作品/IPとのコラボを、画面をイベント種別ごとにサイロ化せず共通モデルで扱う。

## 原則
「イベント」「収集物」「物理地点」を分離する。同一地点に複数コンテンツを紐付けられ、画像が無いコンテンツでもUIが破綻しないことを前提とする。
