## 主要な機能差分

### 1. Rewarded Story Preview
実装済み。
- 未獲得地点の対象ContentBlockを広告視聴後1時間だけ閲覧
- 対象role: description / history / field_guide / story
- スタンプ/実績/カード獲得には影響しない
- Supabase server clock基準
- reopen / resume / 毎分で期限再評価
- Release AndroidのRewarded IDはbuild-time注入
- IDなしReleaseではCTAを非表示

### 2. Version 16 incident → Version 17 prevention
Version 16でRelease Rewarded IDが空だったためCTAが非表示になった。
Version 17 workflowでは、GitHub variable/secretを優先し、未設定時のfallbackを持ち、最終値が空ならbuild failureにする。

### 3. 広告表示Policy
Release Interstitial:
- 起動後3分
- 前回表示から15分
- スタンプ獲得後2分
- 対象画面滞在10秒
- blocking contextがある場合は表示禁止
- natural exitのみ

Banner:
- adaptive bannerを試行
- 高さ50dpを超える場合は通常Bannerへfallback

Rewarded:
- 自動表示しない
- ユーザー明示操作のみ

### 4. 起動性能
初回Flutter frameを優先し、Mobile Ads / local notificationsをdeferred initializationへ移動。Google Maps等とのネイティブmain thread負荷集中を避ける。

### 5. Content visibility
ContentBlockのmetadata `visibility` による always / after_collection / hidden を実装。after_collectionの一部roleだけStory Preview対象とする。

### 6. コレクション
大規模イベントではserver側ページングされたデータを追加ロードできる。UIはすべて/獲得済み/未獲得フィルターを維持する。

### 7. 記念カード
CollectionCardPageをコレクション導線へ統合。Debugではスタンプ不要の表示確認導線を持ち、SCREENSHOT_MODEでは非表示。Android/iOS共通ロジックとして扱う。

### 8. Screenshot mode
`SCREENSHOT_MODE=true` の場合、Banner / Interstitial / Debug記念カード導線を抑制する。撮影用の状態を本番ユーザー導線と混ぜない。

### 9. iOS / Codemagic
iOS bundle identifier、Google Maps、platform-specific Banner/Interstitial Ad Unit、runtime/build configurationを整備。Codemagic unsigned checkとGitHubからのCodemagic control bridgeを整備した。

### 10. Google Play release automation
test track限定workflow、WIF認証、AAB versionCode guard、signing secret復元、AAB artifact保存を実装。production trackはworkflowから選択不可。

### 11. Account deletion
アプリ内削除に加え、メール/パスワード利用者向けWeb削除ページを追加。Webページはpublishable keyのみを使用し、delete-account Function側で認証済みユーザーを削除する。

### 12. Server-side story clock
`story_preview_server_time()` をmigrationとして追加。authenticatedのみexecute可能。コンテンツ/収集/報酬データを変更しない。
