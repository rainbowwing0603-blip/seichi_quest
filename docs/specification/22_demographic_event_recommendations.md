# 年代・性別ベースのイベントおすすめ

## 概要

プロフィールで任意の年代・性別を登録し、イベント参加実績を年代・性別単位で集計して、ユーザーがまだ参加していないイベントをおすすめする。

## プロフィール

- 年代: 未設定 / 10代 / 20代 / 30代 / 40代 / 50代 / 60代 / 70代以上 / 回答しない
- 性別: 未設定 / 男性 / 女性 / その他 / 回答しない
- 未設定でもアプリ利用に影響しない。
- 年代・性別はプロフィールテーブルに保存する。

## おすすめロジック

1. 現在のユーザーが未参加のイベントだけを対象にする。
2. 年代が設定されていれば同年代を優先する。
3. 年代と性別が設定されていれば「年代×性別」を優先する。
4. 統計対象が5人未満の場合は個別属性によるランキングを出さず、全体人気へフォールバックする。
5. 全体人気では参加者数を基準にする。
6. 終了済み・非公開イベントは対象外。
7. 参加済みイベントは過去に離脱していても「参加経験あり」としておすすめ対象外にする。

## プライバシー

- 他ユーザーの表示名・ユーザーID・個別プロフィールはアプリへ返さない。
- Supabaseの集計RPCで統計値だけを返す。
- 集計対象が5人未満の場合は属性別統計を表示しない。
- RPCは認証済みユーザーだけが実行でき、anon/publicからのEXECUTEは拒否する。
